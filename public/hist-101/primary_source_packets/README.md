# HIST 101 Primary Source Packets

Reminder: these packets are meant to be **in-class, flipped-classroom assignments**.

- Students read a short primary source during class and answer the questions while they're there.
- Class time goes to reading and discussion, not lecture. The lecture decks carry the background.
- Each packet is a single HTML page. Students type their answers, check themselves with the Show Answers button, and export a .txt file to upload to Canvas.
- There's no chatbot step and no PDF step.

## Packets
- uncle_toms_cabin/hist101-uncle-tom-student-packet.html: Uncle Tom in Stowe's own words (Chapters 5, 33, 40). It goes with Chapter 13, Lecture 3A, "Uncle Tom: From Hero to Insult".
