# Chapter 2 Cognitive-Load and First-Year Readability Audit

## Result

**Pass.** The pilot follows the low-pressure design specified by the skill.

| Criterion | Result | Evidence or remediation |
|---|---|---|
| One question at a time | Pass | The application renders only the current question. |
| Three questions per set | Pass | Each session draws one Explain, one Use, and one Connect item. |
| No grade, timer, streak, badge, or leaderboard | Pass | No scoring or timed element exists in HTML, CSS, JavaScript, or JSON. |
| Concise stems | Pass | Each stem asks one historical-thinking task and avoids long background narratives. |
| Four parallel choices | Pass | Every item has four direct, sentence-length choices. |
| Respectful feedback | Pass | Feedback uses "Exactly" and "Not quite" and explains the reasoning error. |
| Immediate feedback shorter than walkthrough | Pass | Two concise feedback paragraphs appear first; 3-5 reasoning steps remain collapsed. |
| Optional detail | Pass | Walkthrough and early-course hint use explicit expand/collapse controls. |
| Retry-friendly | Pass | Students can retry the same item or continue without penalty. |
| Stable layout | Pass | Feedback appears below the visible question and choices. |
| Early-course scaffolding | Pass | Early mode displays the thinking move and optional hint. |
| Gradual scaffold reduction | Pass | Mid mode omits hints; late mode reveals the thinking move after submission. |
| Stop after three | Pass | Completion language explicitly says one set is enough. |
| Terminology support | Pass | Transfer strategies and walkthroughs explain cause, context, consequence, comparison, evidence, and sovereignty. |
| Decorative restraint | Pass | The page uses simple cards, no animation-dependent content, and no unrelated imagery. |

## Readability judgment

The language is appropriate for first-year college students and advanced high-school students. The items preserve complex historical relationships while limiting each stem to one decision. Proper names are used only when central to taught cases. No item depends on specialist historiography or outside research.
