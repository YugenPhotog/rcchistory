Christianity Reveal.js deck
============================

Open christianity.html in a browser.

Navigation
----------
Right arrow / Space: next slide or fragment
Left arrow: previous slide or fragment
S: presenter view with PowerPoint speaker notes
F: fullscreen
O: overview

Editing
-------
All ordinary slide text is HTML in christianity.html and can be edited in a text editor.
For temporary in-browser editing, open christianity.html?edit=1. Browser edits are not saved automatically.

Package contents
----------------
- 82 Reveal <section> slides mapped one-to-one to the PowerPoint
- 243 progressive Reveal fragments
- 19 slides with transferred presenter notes
- 35 byte-for-byte original PowerPoint image files in assets/original-media
- Complex grouped diagrams preserved in assets/complex to avoid visual changes
- PowerPoint-rendered slide backgrounds in assets/backgrounds preserve the original theme and layouts
- Local Reveal.js runtime in reveal/; no network connection is required
- deck-manifest.json with media hashes, dimensions, and slide mappings
