Judaism Reveal.js deck
========================

Open judaism.html in a browser.

Navigation
----------
Right arrow / Space: next slide or fragment
Left arrow: previous slide or fragment
S: presenter view with PowerPoint speaker notes
F: fullscreen
O: overview

Editing
-------
All ordinary slide text and tables are HTML in judaism.html and can be edited in a text editor.
For temporary in-browser editing, open judaism.html?edit=1. Browser edits are not saved automatically.

Package contents
----------------
- 60 Reveal <section> slides mapped one-to-one to the PowerPoint
- 219 progressive Reveal fragments
- 23 slides with transferred presenter notes
- 19 byte-for-byte original PowerPoint media files in assets/original-media
- SmartArt on slide 14 preserved in assets/complex to avoid visual changes
- Local Reveal.js runtime in reveal/; no network connection is required
- deck-manifest.json with media hashes, dimensions, and slide mappings
